# Allard Lyman profiles

These temperature-dependent neutral-H/proton Ly-alpha, Ly-beta, and Ly-gamma
profile tables were supplied by Nicole Allard for use and redistribution with
OpenWD. Please cite the relevant Allard line-profile papers listed in the
top-level documentation when using them.

The separate `allard-tlusty205` directory contains the historical profiles
distributed with TLUSTY 205.
